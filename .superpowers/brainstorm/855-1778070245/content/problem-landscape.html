⚠ 理论上直立奖励最高。但核心问题是：早期随机探索时，蹲下的信号更可靠。
网络发现 "降低身体 = 稳定性立刻改善" 比 "努力站直 = 偶尔更高但经常更低" 更容易学习。

阶段 2：蹲下后伸不直腿

物理原因

膝盖弯曲时：

躯干重心前移 + 力臂变短
→ 膝关节需要更大的力矩才能伸直
→ 当前关节强度不足以推起 4kg 躯干

膝关节负载 ≈ 躯干重量 × 弯曲力臂
弯曲越深，需要的力矩越大

奖励层面：

没有 "膝关节角度惩罚"
→ 网络不在乎腿弯不弯
→ 只在乎身体高度和稳定性

蹲下 + 腿弯 = 低重心 = 更稳
网络没有理由伸直腿

阶段 3：尝试迈步 → 倒向弯曲腿一侧

摔倒链
1️⃣ 不对称蹲姿
左腿弯45°
右腿弯30°
→ 重心偏右
→
2️⃣ 迈左腿
右腿单独承重
右髋推不动躯干
→ 躯干向左倾
→
3️⃣ 连锁倾倒
倾斜角速度加速
右腿弯曲无法支撑
→ 向右侧倒下

缺位的奖励信号：

现在有的

  • Alive — 不倒即有
  • Height — 身体高度
  • TrunkStability — 倾斜惩罚
  • CommandTracking — 速度跟踪

现在没有的

  • 膝关节角度正则 — 不关心腿直不直
  • 姿态对称 — 两腿弯度差异无惩罚
  • 重心投影 — 重心是否在支撑多边形内
  • 单支撑稳定性 — 抬腿时躯干能否维持

核心矛盾

网络学到的策略： "蹲低 + 不动 = 最稳定的奖励流"

我们期望的策略： "站直 + 交替迈步 = 更高的总奖励"

当前奖励结构下，前者确实更优。要改变行为，必须改变经济学。
